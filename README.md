This is a full-stack web application built with **Spring Boot (Java)** for the backend and **Angular** for the frontend. 
It is designed to demonstrate a complete CRUD-based application with modular structure and real-world functionality.

## 🚀 Features

- ✅ User-friendly frontend using Angular
- ✅ RESTful APIs with Spring Boot
- ✅ CRUD operations for managing entities
- ✅ MySQL Database integration
- ✅ Organized project architecture
- ✅ Clean code and reusable components

🛠️ Technologies Used

### Backend (Spring Boot)
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

### Frontend (Angular)
- Angular 14+
- TypeScript
- Bootstrap / Angular Material
- HTTPClient for API calls
